# 위상 정렬 (Topological Sort)

## 한 줄 요약

"A는 B보다 먼저" 같은 조건들을 모두 지키는 순서를 찾는다. 사이클이 없는 방향 그래프(DAG)에서만 가능하다.

## 핵심 개념: 진입 차수 (indegree)

노드마다 "나보다 먼저 끝나야 하는 것"의 개수를 센다.
진입 차수가 0인 노드는 지금 바로 실행할 수 있다.

## Kahn 알고리즘 (외워 둘 것)

```python
indegree 계산
queue = 진입 차수가 0인 노드 전부
while queue:
    v = queue.popleft()
    order.append(v)
    for nxt in graph[v]:
        indegree[nxt] -= 1        # v가 끝났으니 조건 하나가 풀림
        if indegree[nxt] == 0:
            queue.append(nxt)
if len(order) != 노드 수: 사이클이 있다
```

BFS와 모양이 거의 같다. 차이는 "방문했나" 대신 "선행 조건이 다 풀렸나(indegree 0)"를 본다는 점이다.

## 사이클 판별

사이클 안의 노드는 서로를 기다려서 진입 차수가 끝까지 0이 되지 않는다.
그래서 결과 길이가 노드 수보다 짧으면 사이클이 있다는 뜻이다.

## 자주 하는 실수

- 번호가 1부터인데 배열을 n칸만 만들기. n+1칸으로 만든다.
- 간선 방향 거꾸로 넣기. "A가 B보다 앞"이면 A → B, indegree[B]++.
- 답이 여러 개일 수 있다는 걸 잊기. "사전순으로 가장 앞선 순서"를 요구하면 큐 대신 **최소 힙**을 쓴다 (백준 1766 문제집).

## 복잡도

O(V + E)

## 서빙 시스템과의 연결

- **LangGraph**: 노드 의존성대로 실행한다. 같은 단계의 노드는 병렬로 돌릴 수 있다 (`agent_workflow.py`).
- **에이전트 루프는 사이클이다**: "답을 보고 다시 계획"하면 DAG가 아니다. LangGraph는 이걸 위상 정렬이 아니라 단계(superstep)를 반복하는 방식으로 처리하고, 무한 반복을 막으려고 `recursion_limit`을 둔다.
- **빌드 시스템, 컴파일러**: 의존성 순서대로 빌드하거나 연산을 배치할 때 쓴다.
