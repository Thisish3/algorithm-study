# algorithm-study

코딩 테스트와 System SW 면접을 준비하며 정리하는 알고리즘 공부 노트.
주제마다 예제 코드와 `NOTES.md`(개념, 외울 틀, 자주 하는 실수, 연습 문제)를 둔다.

| # | 주제 | 언어 | 서빙 시스템과의 연결 |
|---|---|---|---|
| 01 | [Power of Two Random Choices](01-power-of-two-choices/) | Python, C, C++, Rust | 디스크·GPU에 부하 고르게 나누기 (S3, 라우터) |
| 02 | [BFS](02-bfs/) | Python, C++ | 최단 거리, 홉 수 |
| 03 | [위상 정렬](03-topological-sort/) | Python, C++ | LangGraph 노드 실행 순서, 병렬 단계 |

## 공부 방법

1. 읽기: 예제를 한 줄씩 소리 내어 설명한다.
2. 백지 재작성: 파일을 닫고 빈 파일에 다시 짠다. 막히면 그 줄만 보고 다시 닫는다.
3. 결과 대조: 예제 입력으로 실행해 정답과 비교한다.
4. 연습 문제: `NOTES.md`의 문제를 같은 방식으로 푼다.
