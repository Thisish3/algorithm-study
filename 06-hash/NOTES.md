# 해시 (딕셔너리 · 집합)

## 한 줄 요약

"이 키가 있나, 있으면 값이 뭔가"를 평균 O(1)에 답한다. 묶어서 세기, 중복 찾기, "앞에서 본 적 있나"에 쓴다.

## 왜 쓰나: 두 예제

**묶어서 세기** (`tenant_usage`): 게이트웨이 로그에서 테넌트별 토큰 합과 요청 수를 구하고 상위 K개를
뽑는다. 테넌트 이름을 키로 합계를 쌓으면 한 번 훑기로 끝난다(O(n)). 마지막 정렬은 테넌트 수 T에 대해 O(T log T).

**누적합 + 해시** (`window_sum_k`): 분 단위 토큰 사용량에서 합이 정확히 K인 연속 구간의 개수.
구간 합 = 누적합[j] − 누적합[i]이므로, 지금 누적합에서 K를 뺀 값이 **앞에서 몇 번 나왔는지**를
해시에 세어 두면 된다. 모든 구간을 보면 O(n²), 이 방식은 O(n). 음수가 있어서 투 포인터가 안 되는 경우에도 된다.
예제 입력에서 7개가 나오고, 무작위 입력 500개로 O(n²) 정답과 비교해 맞는 것을 확인했다.

## 틀 (외워 둘 것)

```python
from collections import defaultdict, Counter
cnt = defaultdict(int); cnt[key] += 1        # 없는 키는 0에서 시작
Counter(words).most_common(3)                # 빈도 상위
seen = set(); if x in seen: ...; seen.add(x)

# 누적합 + 해시: 합이 K인 구간 수
seen = defaultdict(int); seen[0] = 1         # 처음부터 시작하는 구간
prefix = ans = 0
for x in a:
    prefix += x
    ans += seen[prefix - k]
    seen[prefix] += 1                        # 세고 나서 넣는다 (길이 0 구간 방지)

# 정렬 키: 값 내림차순, 같으면 이름 오름차순
sorted(d, key=lambda t: (-d[t], t))
```

```cpp
std::unordered_map<std::string, long long> cnt; cnt[key] += 1;   // 없으면 0으로 생성
auto it = m.find(key); if (it != m.end()) ...;                   // 읽기만 할 때는 find
std::unordered_set<int> seen; seen.count(x); seen.insert(x);
```

## 자주 하는 실수

- **C++ `m[key]`로 읽기**: 키가 없으면 0으로 **새로 만든다**. 존재 확인·읽기만 할 때는 `find`/`count`.
- **누적합 해시에서 넣는 순서**: 세기 전에 넣으면 K=0일 때 길이 0 구간까지 센다. 세고 나서 넣는다.
- **`seen[0] = 1` 빠뜨리기**: 처음부터 시작하는 구간을 못 센다.
- **정수 넘침**: 누적합은 금방 커진다. C++은 `long long`.
- **정렬에서 동점 처리**: 문제의 동점 규칙(이름순, 먼저 나온 순)을 키에 넣는다.
- **해시가 항상 O(1)은 아님**: 최악은 충돌로 O(n). 일부 채점 사이트는 `unordered_map`을 깨는 입력을 넣는다. 의심되면 `map`(O(log n))이나 `reserve`.
- **순서가 필요한데 해시를 씀**: 해시는 순서가 없다(파이썬 dict는 넣은 순서만 유지). 키 순서가 필요하면 정렬하거나 `map`.

## 복잡도

넣기·찾기 평균 O(1), 최악 O(n). 두 예제 모두 O(n) (+ 결과 정렬).

## 서빙 시스템과의 연결

- **prefix 캐시**: 블록 해시 → KV 블록 위치를 해시 표로 찾는다. 키를 앞 블록 해시와 이어 만드는 이유는 개념 글 "prefix 캐시의 키는 왜 체인 해시여야 하나"(94번)에 있다.
- **게이트웨이 집계**: 테넌트별 사용량·요금 (예제 1).
- **중복 요청 제거**: 요청 ID 집합으로 재시도 중복을 거른다.
- **일관 해싱**: 키를 서버에 나눌 때 서버가 늘거나 줄어도 다시 배치되는 키를 최소로 (캐시 서버, 세션 고정 라우팅).
