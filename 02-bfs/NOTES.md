# BFS (너비 우선 탐색)

## 한 줄 요약

가까운 곳부터 차례로 퍼져 나가는 탐색. 간선 비용이 모두 같을 때 **최단 거리**를 보장한다.

## 왜 최단 거리가 되나

큐는 먼저 넣은 것을 먼저 꺼낸다. 그래서 거리 1인 칸을 전부 꺼낸 뒤에야 거리 2인 칸을 꺼낸다.
어떤 칸에 처음 도착한 순간이 곧 가장 짧은 경로다.

## 틀 (외워 둘 것)

```python
from collections import deque

dist[start] = 1          # 방문 표시 겸 거리
queue = deque([start])
while queue:
    cur = queue.popleft()
    for nxt in neighbors(cur):
        if 범위 안 and 갈 수 있음 and 방문 안 함:
            dist[nxt] = dist[cur] + 1   # 넣을 때 표시한다
            queue.append(nxt)
```

## 자주 하는 실수

- **꺼낼 때 방문 표시하기**: 같은 칸이 큐에 여러 번 들어가 느려지거나 시간 초과가 난다. 넣을 때 표시한다.
- **파이썬에서 `list.pop(0)` 쓰기**: O(n)이라 느리다. `deque.popleft()`를 쓴다.
- **범위 검사 순서**: `grid[nr][nc]`를 보기 전에 `0 <= nr < n`부터 확인한다.
- **시작 칸 거리를 0으로 둘지 1로 둘지**: 문제에서 "지나는 칸 수"인지 "이동 횟수"인지 읽고 정한다.

## 복잡도

칸 수를 V, 이웃 관계 수를 E라 하면 O(V + E). 격자 N×M이면 O(NM).

## DFS와 차이

| | BFS | DFS |
|---|---|---|
| 자료구조 | 큐 | 스택 (또는 재귀) |
| 최단 거리 | 보장 | 보장 안 함 |
| 잘 맞는 문제 | 최단 거리, 단계별 퍼짐 (토마토) | 모든 경우 탐색, 연결 요소 세기 |

## 서빙 시스템과의 연결

- 에이전트가 툴을 몇 번 거쳐야 목표 상태에 닿는지 = 그래프 최단 거리.
- 네트워크에서 노드 사이 홉 수 세기도 BFS다.
